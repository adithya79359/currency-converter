# Currency Converter 🌍

A web-based Currency Converter application built using **HTML, CSS, and JavaScript** that converts currencies in real time using a public exchange-rate API.

---

## 🚀 Project Overview

This project allows users to convert an amount from one currency to another by selecting currencies from dropdowns.  
It fetches **live exchange rates** from an external API and updates results dynamically without reloading the page.

---

## 🛠️ Features

- Real-time currency conversion using live API data
- Dynamic currency dropdowns populated programmatically
- Automatic country flag updates based on selected currency
- Input validation for safe and accurate conversions
- Clean and responsive user interface
- Error handling for API failures

---
